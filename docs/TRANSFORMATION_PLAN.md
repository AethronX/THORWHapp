# «ثروتي» — تقرير الفحص وخطة التحوّل (٢٨ نوفمبر ٢٠٢٦)

> ردٌّ على «البرومبت الرئيسي». **قاعدته: لا أدّعي تنفيذ ما لم يُنفَّذ.** كل ✅ أدناه له ملف واختبار؛
> و🟡 جزئي؛ و❌ غير موجود. «جهاز حقيقي» لم يُستخدم في أي اختبار حتى الآن.

## ١. الوضع الحالي باختصار
تطبيق Expo SDK 57 / React Native 0.86، **محلي بالكامل** (SQLite، مخطط v2، عشرة جداول)، ٢٢ شاشة، ١٦ وحدة
منطق، **٣٧٥ اختبارًا آليًّا تمرّ**. لا خادم، لا تحليلات، لا SDK أعطال، **لا أي `fetch` في الكود**، ولا `console`
يسجّل بيانات مالية. الحزمة الوحيدة القادرة على الاتصال بالشبكة `expo-updates`، ومضبوطة على `NEVER` في الإنتاج.

## ٢. نقاط القوة (مثبتة)
- **الحسابات:** أعداد صحيحة بوحدات العملة الصغرى، ٢٦ عملة بأسس ISO، تحليل مبالغ يرفض الغامض («12,500» بالريال
  العماني) بدل التخمين.
- **المحرّكات:** إرشاد مرتّب بخطوة واحدة وسببها، مبادئ الثراء، الشخصية المالية ببوابتين، مواسم أم القرى.
- **الصدق في الكود:** «لا حكم بلا بيانات» مطبّق في كل محرّك؛ قسم الاستثمار بلا رقم عائد مملوء مسبقًا (D-050).
- **الجودة:** مراجعة عدائية أصلحت ١٢ خطأً مثبتًا (D-054)، اختبار توقيت صيفي، تباين WCAG AA مختبر آليًّا.

## ٥. الخطة (بترتيب البرومبت، مع ما يتأثر)
| المرحلة | المحتوى | الملفات الرئيسية | الحالة |
|---|---|---|---|

| ٢. الرئيسية | الالتزامات القادمة، حالة الطوارئ، صافي الثروة؛ ترتيب «أين أنا / ما يحتاج انتباهي / الخطوة» | `(tabs)/index.tsx`, `selectors.ts` | التالية |
| ٣. الإرشاد | `dataSufficiency` و`reviewOn` لكل خطوة، وعرضهما | `domain/guidance.ts`, `ui/Guidance.tsx` | |

| ٧. المراجعات | أسبوعية وشهرية، سجلّ إنجازات بلا لوم | جديد | |
| ٨. الإقفال | تشفير القاعدة (SQLCipher عبر `expo-sqlite` + مفتاح في `expo-secure-store`)، فحص النصوص والشاشات، **جهاز حقيقي** | | يحتاج بناء تطويري وجهازك |

**قاعدة كل مرحلة:** اختبارات تفشل أولًا ← تنفيذ ← كل الاختبارات ← لقطات ← توثيق ← دفع. لا إعادة كتابة شاملة:
لا شيء في الفحص يبرّرها.

## ٦. ما لا أستطيع فعله من هنا
- **اختبار جهاز حقيقي** (بند القبول ١٣): يحتاجك أنت.
- **مراجعة قانونية** لقسم الاستثمار و**شرعية** للزكاة: تحتاج مختصّين.
- **قياس البطارية والأداء الفعلي**: لا يُقاس في متصفح.
